# Circuit Forge — Prototype

GDD v0.2 기반 인크리멘탈 + 퍼즐 하이브리드 게임의 **핵심 골격(big frame)** 프로토타입.
외부 의존성 없는 단일 HTML 파일입니다. `index.html`을 브라우저로 열면 바로 플레이됩니다.

## 플레이 방법
- **배선:** 좌클릭 드래그로 전선을 긋습니다 (무료).
- **부품 배치:** Shop에서 부품 선택 후 그리드 클릭.
- **삭제:** 우클릭(또는 🧽 삭제 도구).
- **스위치:** 클릭으로 ON/OFF 토글.
- 닫힌 사각 루프 안에 **배터리 1개 이상 + 저항/LED 1개 이상**을 넣으면 회로가 작동하며
  연산력(FLOPS)을 생산하고, 1:1로 자금($)이 됩니다.

## 구현된 핵심 루프 (GDD 매핑)
- 그리드 & 드래그 배선, 부품 배치/삭제 — §4
- 회로 유효성 판정(폐루프/전원/부하) — §4.4
- Wire Efficiency(바운딩박스 근사) · Conductor Cap · 전압 매칭 · 병렬 보너스 · Heat Modifier — §4.5
- 연산력 → 자금 변환, 상점 구매, 그리드 확장(8×8→16×16) — §3, §4.1
- Heat 시스템 & 방열판 — §3.3
- Flux 효율 마일스톤, 도체 등급 업그레이드 — §3.4, §5.6
- 통계 패널, localStorage 세이브
