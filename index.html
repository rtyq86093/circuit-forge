⚡ 전기 기초 — 전류 중심 아케이드 모델

회로의 핵심: PSU는 Amps(A)를 공급하고, 부품은 Amps를 요구합니다.

공급률 = min(1, PSU 공급 A ÷ 전체 요구 A)

① PSU는 Amps를 공급한다
각 PSU는 최대 공급 Amps를 가집니다. 병렬 PSU는 Amps가 합산됩니다. PSU가 부족하면 공급률이 떨어져 모든 출력이 비례 감소합니다. 고장은 과열·역극성·단락에서만 발생합니다.

② Logic 출력 = FLOPS × 공급률 × Clock × 전압 × Wire 효율
공급률이 100%일 때 최대 성능을 냅니다. 온도가 70°C를 넘으면 출력이 감소하고 100°C 초과 시 영구 고장입니다.

③ Resistor — 고전압 분기 안정화
Resistor를 분기에 놓으면 그 분기의 발열을 ×0.70으로 낮춥니다(출력은 ×0.88). 고전압 분기는 발열이 출력보다 빨리 올라 냉각만으로 부족하므로, 저항으로 발열을 직접 낮춰 100°C 고장을 막습니다. Precision은 손실이 적고, Variable은 클릭으로 실시간 조절 가능합니다.

④ 전압 오버클럭 (Upgrades에서 해금)
· 14V: 출력 ×1.25 · 요구 전류 ×1.20 · 발열 ×1.35
· 16V: 출력 ×1.55 · 요구 전류 ×1.45 · 발열 ×1.65
고전압일수록 출력보다 발열이 더 빠르게 오릅니다. 강력하지만 그대로 두면 100°C를 넘겨 고장 위험이 쌓이므로, 저항으로 안정화하거나 냉각을 늘려야 합니다.

⑤ PSU 용량 계획 (12V 기준)
요구 Amps = Clock 0.10A + Logic Cell 0.50A × 개수 + LED 0.10A + …
이 합계가 PSU 공급 Amps 이하여야 공급률 100%가 유지됩니다.

핵심 5가지: 전압↑=빠름+뜨거움 / 병렬분기↑=전류필요↑ / PSU 부족=출력저하 / Resistor=분기안정화 / 냉각=오래지속

📈 게임 진행 가이드

성장 사다리: 기본 회로 → 효율·안정화 → Blueprint → Chip 압축 → Tape-out → 공정 발전 → Module → Gate → ALU → CPU Core …

🧩 Phase 2 진입 조건
아래 5가지를 모두 보드에 적용하면 Phase 2가 열립니다(보유가 아니라 실제 배치/사용 기준). 진행 상황은 Shop 탭 상단에 ✓/✗로 실시간 표시됩니다.
① 16×16 보드 확장 · ② 12.5A↑ PSU(150W급) 배치 · ③ Fast/Overclocked Clock 배치 · ④ 12.5A↑ Fuse 배치 · ⑤ OFC↑ 배선 사용
진입하면 Capacitor·Diode·Transistor·Cooling Fan 설계가 Upgrades에 열립니다.

🔁 Tape-out (런 리셋·성장)
누적 7M FLOPS에서 Tape-out하면 BP를 얻고 런이 초기화됩니다. 실행 전 모달에 예상 등급 D/C/B/A/S와 점수(Compute·효율·열 안정성·밀도·Blueprint)가 표시됩니다. 등급이 높을수록 더 많은 BP와 공정 경험치를 얻습니다. Flux·BP·Blueprint·등록 IP·공정 세대·이월 Chip은 런을 넘어 유지됩니다.

🏭 공정 세대 (processNode)
Tape-out 등급에 따라 공정 경험치(D1·C2·B3·A5·S8)가 쌓여 PCB Prototype → SSI → MSI → LSI → VLSI → 180nm … 3nm으로 발전합니다. 세대가 오르면 Chip·IP 압축 시 출력 감쇠가 완화되고 발열이 줄어듭니다. 또한 일부 상위 부품(Gate 등)의 해금 조건이 됩니다. 현황은 Stats 탭에서 확인하세요.

📐 Blueprint (설계 자산)
고장 없는 유효 회로를 Blueprint로 저장하면 자동으로 분석·등급(Crude→Working→Stable→Efficient→Compact→Production)이 매겨집니다. 면적당 출력·최고 온도·Wire Efficiency가 기준입니다. Blueprint는 수동 가이드/Auto-Solderer 시공, Chip 압축, Module 인증, IP 등록의 재료가 됩니다.

🗜 Chip 압축 & 품질
Blueprint를 ✦Flux로 1×1 Compressed Chip으로 압축합니다. 공간을 아끼는 대신 출력 60%·발열 100%(한 칸 집중)라 냉각이 거의 필수입니다. 원본 효율·온도·밀도로 품질(Crude→Stable→Efficient→Compact→High-Speed→Golden Sample)이 결정되며, 공정 세대가 높을수록 출력 보존이 좋아집니다.

🧩 Module Lab — Module 인증
저장된 Blueprint를 역할별 Module로 인증합니다. Logic(Compute·출력50·90°C), Clock(Clock·공급률95%), Power(PSU·Fuse), Cooling(Heatsink/Fan·70°C), Gate(Gate 2개·90°C), Register(Register/Latch·공급률90%). 인증 Module은 상위 부품 해금과 ALU/CPU 제작의 전제 조건입니다.

🔷 IP 등록 (영구 부품)
Tape-out B등급 이상에 도달하면 우수 Blueprint(Stable 이상·면적 16칸 이하)를 Module Lab에서 커스텀 IP로 등록할 수 있습니다. 등록한 IP는 Shop의 [커스텀 IP]에서 일반 부품처럼 반복 구매·배치되며, 원본 Blueprint를 삭제해도 유지됩니다(슬롯 4개).

🔢 Gate · Register 부품
Gate(NAND/NOR/XOR/Gate Array)는 저출력 Compute지만 서로 다른 종류를 섞으면 다양성 보너스(×1.05~1.20)를 줍니다. Register/Memory(Latch/Flip-Flop/Register)는 직접 출력이 없고(유효 회로 필수 아님) ALU/CPU 인증에 쓰입니다. 해금에는 공정 세대 + 인증 Module + 누적 FLOPS 조건이 필요하며, 잠긴 이유는 Upgrades 탭에서 ✓/✗로 표시됩니다.

🧮 ALU 제작
Module Lab의 ALU 섹션에서 Gate 2개+Register+Clock·출력 500↑·공급률 90%·90°C↓·효율 85%↑ 회로를 ALU Module로 인증합니다. 인증 후 ALU Chip(✦18, 출력 보존 ×1.45)을 만들면 CPU Core의 재료가 됩니다.

🖥 CPU Core 제작
ALU·Register·Clock·Power Module을 모두 인증하고, 총 출력 2.5k↑·공급률 95%·85°C↓ 회로를 CPU Core로 인증합니다. CPU Core Chip(✦30, 출력 보존 ×2.0)은 현재 최종 고성능 부품입니다. ALU Chip을 회로에 넣으면 출력을 쉽게 끌어올릴 수 있습니다.

📦 CPU 지원 부품 — 배치가 중요해진다
· Cache(L1/L2): 가까운 CPU/ALU Chip의 출력을 올립니다. 맨해튼 거리 1~2칸=+30%, 3~5칸=+21%, 6칸+=+12%. 칩 옆에 붙여 두세요.
· VRM: 보드에 VRM이 없으면 CPU Core Chip 출력이 ×0.8로 제한됩니다. CPU 칩을 쓰면 VRM을 함께 배치하세요.
· Clock Tree Buffer: 서로 다른 주파수 Clock을 섞을 때 생기는 동기화 손실(×0.95)을 제거합니다.
해금에는 공정 세대(MSI~LSI)와 Power/Register/Clock Module 인증이 필요합니다.

🗂 탭 구성 안내
· Upgrades 탭: 이번 런에서 자금으로 사는 해금(부품 설계·배선 등급·전압 오버클럭). 부품은 Shop과 같은 계열 그룹으로 묶여 보입니다.
· BP 강화 탭: Tape-out으로 얻은 BP로 사는 영구 강화(런을 넘어 유지). 이번 런 한정인 Upgrades와 분리했습니다.
· Blueprints 탭 · Chip 인벤토리: 칩이 많으면 [🔍 한눈에 보기] 버튼으로 그리드 창을 열어 CPU/ALU/일반 필터로 한눈에 찾고 바로 배치할 수 있습니다.

❄ 냉각: 방열판 vs 냉각팬
· Heatsink: 부품 1칸 위에 장착하는 수동 방열판. 전력이 필요 없고 통전 여부와 무관하게 항상 식힙니다.
· Cooling Fan: 부품 위에 2×2로 덮어 부착하는 면적 냉각기입니다. 덮은 4칸 중 통전 중인 분기가 있으면 회전하며 그 영역 전체를 한꺼번에, 방열판보다 강하게 식힙니다. 공급률이 높을수록 빠르게 돌고 더 강하게 냉각하며, 전력이 없으면 멈춥니다(날개 회색=정지). 칩처럼 발열이 몰리는 구역에 올려 두세요.
· 중첩 가능: 같은 부품에 방열판과 팬을 함께 부착하면 냉각이 합산됩니다. 팬은 선택 후 영역 클릭으로 부착하고, 덮인 칸을 다시 클릭(또는 삭제 툴)하면 회수됩니다.

🔀 배선 분기 (Junction 폐지)
이제 전선만으로 3방향 이상 갈라지는 분기를 만들 수 있습니다. 전선이 T자·십자로 만나는 칸은 자동으로 전기적 분기점이 되어 병렬 회로를 구성합니다. 별도의 Junction 부품은 더 이상 필요 없으며, 기존에 놓았던 Junction은 자동으로 4방향 전선으로 바뀝니다.

🧭 극성 단자 편집 (모든 극성 부품)
극성(+/−)이 있는 모든 1×1 부품(커넥터·Clock·Logic·Gate·Register·Diode·Capacitor·Transistor·VRM·레귤레이터·Chip 등)은 선택 도구로 클릭해 +/− 단자가 놓일 면을 바꿀 수 있습니다. 회로 배치에 맞춰 단자 방향을 자유롭게 돌려 연결하세요.

🏅 인증 등급 (D~S)
ALU·CPU 인증은 통과/실패만이 아니라 최소 조건을 얼마나 넘겼는지로 D~S 등급이 매겨집니다. 채점은 출력 마진·공급 여유·열 여유·설계 다양성 네 축을 봅니다. 등급이 높을수록 만드는 Chip의 출력 배율이 커지며(ALU ×1.30~1.70 · CPU ×1.70~2.40, 모두 B등급이 기존 기준값), 첫 A/S 인증에는 ✦ Flux 보너스가 붙습니다. Module Lab의 카드에서 예상 등급과 마진 바를 미리 확인하세요.

🧭 다음 목표 패널
Phase 2 이후 좌측 상단 안내 패널은 전 시스템을 살펴 지금 할 최선의 행동 1개를 제시합니다. 영구 고장·과열 경고, 인증 가능한 Blueprint, 등록 가능한 IP, 해금 가능한 설계, Tape-out 진척을 우선순위 순으로 안내하며, 해당 탭으로 바로 가는 버튼을 제공합니다. 인증 조건이나 회로 진단이 미충족이면 "→ 처방" 힌트로 고치는 방법을 함께 보여줍니다.

🛒 상점 사용 팁
배선 구매 목록에서 배선 줄을 클릭하면 그 등급이 바로 선택되어 드래그로 그릴 수 있습니다(● 사용 중 표시). 부품 상점 상단의 "📄 전체 목록 / 📑 분류 탭" 버튼으로 보기 방식을 바꿀 수 있습니다 — 부품이 많아지면 분류 탭으로 전환해 계열별로 나눠 보면 스크롤을 줄일 수 있습니다.

❄ 칩 발열 (완화)
칩은 원 회로 발열을 한 칸에 응축하지만 70%만 전달하도록 완화됐습니다(이전 100%). 또한 인증 등급(ALU/CPU D~S)·칩 품질(Crude~Golden)이 높을수록 발열이 더 낮아집니다 — 잘 설계할수록 시원한 칩이 됩니다. Heatsink·Fan의 방열 성능도 상향되어, 적정 설계 + 충분한 냉각이면 칩도 안정적으로 가동됩니다. 다만 무냉각이거나 Overclock·16V로 과하게 밀어붙이면 여전히 녹으니 냉각 투자와 클럭/전압 균형이 중요합니다. (이미 만들어 둔 칩은 냉각 상향 혜택은 즉시 받지만, 발열 감소分은 다시 생성해야 적용됩니다.)

▥ 보드 히트싱크
Heatsink는 부품 위에 장착하는 것 외에 빈 보드 칸에도 깔 수 있습니다. 빈 칸의 보드 히트싱크는 히트파이프가 보낸 열을 대기로 내보내는 방출판이며 자체 온도를 가집니다(마우스를 올려 확인). 인접한 보드 히트싱크끼리는 경계가 사라져 하나의 큰 방열판이 되어 더 많은 열을 받아냅니다(드래그로 넓게 깔기). 그 위에 팬을 얹으면 — 파이프로 연결된 부품이 작동 중일 때 — 팬이 돌며 방열이 크게 늘어납니다. 지우개로 회수합니다. (※ 예전의 '인접 부품 직접 냉각'은 제거되었고, 이제 방출판은 반드시 히트파이프로 부품 히트싱크와 이어야 효과가 있습니다.)

┃ 히트파이프 (열 배관 · 레이어 2 오버레이)
히트파이프는 배선처럼 드래그해 그리며, 그은 방향으로만 이어집니다. 부품(1층)보다 한 층 위(2층)라 부품·히트싱크 위를 지나갈 수 있습니다(레이어 구성: 부품 < 부착 히트싱크·히트파이프 < 팬). 부품에 부착한 Heatsink 위에 파이프를 올리면 그 부품이 열원, 보드 히트싱크 위에 올리면 방출판이 되어 둘을 이으면 열이 방출판으로 흘러 식습니다. 냉각 세기는 현실적인 전도 모델을 따릅니다 — 등급이 높을수록(굵을수록) 전달 효율↑, 파이프를 많이 깔수록 전달량↑, 방출판이 크고 팬이 있을수록 더 많이 받아냅니다. 방출판이 포화되면 전달도 막히니 방열(큰 plate·팬)도 함께 키우세요. 지우개로 회수합니다.
